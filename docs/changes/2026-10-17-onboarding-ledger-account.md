# 初始設定整合幣別、帳本與帳戶

入口：首次 App 登入並啟用授權後的初始設定；Web 無帳本時顯示相同歡迎流程。

原本個人化引導按「開始使用」會卸載並返回舊 PageView 的幣別頁；按「上一步」就回到已啟用的金鑰頁。現在個人化、建立帳本（名稱＋幣別）、建立帳戶都在同一個流程；帳本為必填，帳戶可略過。略過個人化只會前進到建立帳本，完成帳本與處理帳戶步驟後才記錄 onboarding_done。

- `welcome_page.dart` 刪除舊幣別與分類頁，授權完成後改掛完整引導。建立帳本使用正式 repository 與同步，保留已建立 ID 防止失敗重試新增多本；分類由 Cloud 自動建立，空分類時沿用本機 seed 備援，不自動新增帳戶。首次引導先啟動外觀持久化，避免 Splash 讀回舊設定。
- `onboarding_personalize_flow.dart` 加入帳本名稱／幣別與可略過帳戶步驟。建立後返回不會重建帳本，未建立時返回會到 AI。App 新增帳戶沿用 `AccountEditPage` 並預選剛建立帳本的幣別，取消後回到引導。
- 歡迎與授權閘門只有到期日真的早於現在才顯示「已到期」；授權有效時歡迎頁的金鑰步驟提供繼續按鈕。登入前頁面不允許滑動繞過送出驗證。
- Web `WelcomeOnboarding` 同步加入必填帳本／可略過現金帳戶（初始餘額 0），使用正式 API。開始引導後鎖定顯示狀態，避免即時同步發現新帳本就把帳戶步驟卸載。完成偏好但仍無帳本的舊版帳號直接進帳本步驟。Web 完成建立後才刷新帳本與寫入完成旗標。
- 後續可從「資產」新增其他帳戶；帳本設定保持既有入口。功能導覽沿用 `accounts.v5`、`ledger.settings.v4`，更新既有新增帳戶／帳本設定步驟文字，銜接初始設定與日後管理。更新 4.0.0 新功能公告，無新增同步欄位或資料庫版本。

驗證：Flutter 引導與完成旗標測試包含必填、略過、返回、失敗重試與建立帳戶；Web 型別與觸發條件測試。Flutter 相關 25 項測試與 Web 20 項測試通過，初始設定頁靜態分析與 Web 型別檢查通過。此次未部署，尚未實機驗證。
