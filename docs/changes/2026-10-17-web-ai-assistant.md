# Web 浮動 AI 助手

Web 登入後於右下角提供 AI 助手。點擊開啟 Messenger 式小視窗，沿用帳好嗎的圖示、主題色與玻璃材質，支援桌面放大、手機版視窗、亮暗色、快捷問題、串流回覆、停止與重試、複製、清除及可選連續記憶。

## 對話與資料

- `POST /api/v1/ai/chat` 使用現有 AI provider 設定；未設定或明確停用助手時回傳設定指引。先驗證登入與帳本權限，再呼叫模型。
- 模型只能選擇 14 個唯讀工具，包含收支統計、交易、帳戶、預算、欠款、週期性收支、分期、專案、股票持股／交易／已實現損益／股利、刷卡推薦與信用卡帳單。每次最多三個工具；身份、帳本與權限由伺服器注入。
- 查詢重用既有 read handler、business_time 與統計口徑，不自行重算拆帳收支。跨帳本的股票結果與快取報價會在模型上下文中標明；分頁與截斷結果不得當作完整總額。
- 明確記帳意圖沿用 parse-tx-text，只回傳草稿。使用者確認／修改後才透過既有批次交易 API 寫入同步事件。卡片顯示實際儲存的金額、備註與筆數；批次寫入補上 account_group 檢查，草稿選單也排除群組。
- 對話按登入使用者及帳本分開儲存在此瀏覽器（最多 80 則）；切換帳本取消進行中的回覆。連續記憶預設關閉，開啟前說明會將最近八則文字對話傳送至使用者設定的 AI 服務商。
- 前端以 React 文字節點顯示 Markdown 子集，不執行模型輸出的 HTML。伺服器不將 provider 原始錯誤或金鑰傳回介面。

## 開關動畫

- 視窗保持掛載，採 200ms 的 transform／opacity 過渡，從右下角略微縮放展開、收回；快速反向操作從當下畫面接續。
- 關閉立即停用互動與鍵盤焦點，淡出後才隱藏。保留訊息和捲動位置。
- 入口圖示以 160ms 交叉淡化。鍵盤開啟／Escape 立即完成，關閉後焦點回入口；減少動態效果改成短淡化。
- 手機版依 visualViewport 調整高度，避免輸入區被虛擬鍵盤遮住；桌面開啟自動聚焦輸入框，手機等使用者點擊後才聚焦。

- 動畫中途反向的瀏覽器檢查：同一 DOM 節點，關閉中 opacity 0.156989，反向開啟的起始值仍為 0.156989，終點 1。遠端 WebKit 背景分頁會暫停動畫，因此此檢查用瀏覽器 Animation API 定位中間影格，並切回分頁檢視完成畫面。

瀏覽器測試使用獨立 SQLite、測試帳號與固定 AI 回覆；讀取、草稿及儲存走實際 API，不使用正式帳務，也未發出外部模型請求。真實服務商連線與回覆品質仍需使用已配置的服務商驗收。
