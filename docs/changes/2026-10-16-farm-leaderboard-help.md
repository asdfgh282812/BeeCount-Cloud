# 2026-10-16 排行榜計算方式說明

## 入口與互動

Web「農場排行榜」的四個榜籤右側新增獨立問號按鈕。切換榜後，按鈕的無障礙名稱、對話框標題與內容都跟隨目前榜單；說明不依賴 API 成功載入。窄螢幕保留獨立按鈕，長文可捲動。

App「農場 → 農友 → 每週排行榜 → 選榜」每個選項右側新增問號，點擊只開啟該選項的說明，不選榜、不關閉選單、不呼叫排行榜 API。對話框使用既有 BeeDialog 與捲動內容，關閉後可繼續選榜。

## 計分來源

說明對齊 `src/services/game/social.py::build_boards`、`scoring.py::score`、`balance_v1.json` 和 `engine.py` 的收成事件：記帳綜合分數、收成當下市值、成功偷菜次數、自家看門狗抓到小偷次數。共用說明包含週界線、週結算與同分排序。

雲端結算目前沒有向 score 傳入 monthly_budgets，故預算項目不可用並移除其分母權重；文字明示此現況，不把保留的預算權重描述為正在計分。此變更只增加說明，不改計分與既有歷史名次。

Web 繁中、簡中、英文與 App 對應語言採相同內容；App 韓文沿用既有農場文字的英文備援慣例。

## 實作與驗證步驟

1. 核對後端規則，再補上各語言四榜說明與共用排序說明。
2. Web 沿用 Dialog；App 沿用 BeeDialog，問號事件與選榜事件獨立。
3. 執行 i18n 與排行榜契約測試、TypeScript 檢查、Flutter 選榜與說明互動測試。
4. 瀏覽器以隔離資料操作實際排行榜元件，確認四榜內容、關閉與窄螢幕捲動。

## 自己的分數辨識

App 的自己列原本把「我的分數」與農場名稱串在同一段文字中，改為獨立的主題色粗體徽章；Wrap 讓長暱稱與標記可自然換行。自己的右側分數同步加粗並使用 primaryStrong，徽章背景採 primarySoft，維持深淺主題可讀性。Web 的「我」標記同步增加字重與邊框，自己的分數也使用 primaryStrong 粗體。其他玩家分數與排名規則不變。
