# M2 PH02：逐卡信用卡提醒（Cloud / Web）

對應 App 計畫 `../BeeCount-main/BeeCount-main/docs/roadmap/4.0.0/M2-PH02-plan.md`，完整理由與跨端限制見 App `docs/changes/2026-10-16-v4-m2-ph02.md`。

## 入口及行為

Web 頭像選單 → 信用卡繳費提醒（`/app/settings/reminders`），或資產 → 帳戶詳情 → 信用卡繳費提醒。單卡以 `?account=<syncId>` 開同一頁；子卡指向合併帳單主帳戶。全域預設只影響繼承卡，關閉繼承即複製有效值建立獨立覆寫，還原時移除覆寫。

## 實作

- 既有 `profile.notification_settings` 增加 `cc_settings_version` 與 `cc_card_overrides`（syncId → 完整 cc_* 設定）；既有 JSON 欄位足夠，無 migration、account wire 或 projection 改動。Web API types 補上既有 notification_settings，儲存前先讀最新 profile 以保留手機記帳提醒等無關值。
- `src/services/card_reminder_settings.py` 是設定解析／時間與日期 gate。Cloud 舊行為從未讀取 App 全域開關，因此缺版本標記的帳戶保留固定四種提醒，不能直接採用既有 false prefs 而突然停止通知。只有明確修改新版全域設定／該卡覆寫才採用新設定；只改單卡不影響其他舊卡。
- `credit_card_reminders.py` 讀 profile 後沿用 BillingSchedule、LEDGER_TIMEZONE、帳單應繳與 billing-root 判斷。新版依時間、提前天數、連續天數產生提醒；結算在實際結帳日隔天。同日可有多個不同 kind；新版逾期 payload 帶 `reminderDate`，同日去重但次日可繼續，舊模式仍只發一次逾期。
- `SettingsRemindersPage` 及 `cardReminderSettings.ts` 共用同一資料契約，補載入／空／失敗、繼承／覆寫／還原與英／簡中／繁中。路由、頭像選單與帳戶捷徑一併接通。

## 限制與交付

未部署或合併 main，兩邊均留在 feat/v4-dev。真實多裝置 profile 同步、手機 OS 授權與通知實際彈出仍待實機驗收，未用 fake API 測試冒充完整跨裝置完成。

沿用 profile 整包替換（多裝置同時寫入仍最後寫入優先）、Cloud 查任一子卡交易帳本計算應繳等限制；舊客戶端整包回推仍可能遺漏新欄位，跨端完整使用需一起升級。手機通知權限、OS 預排由 App 負責，Web 通過 Cloud 通知中心接收；不新增 APNs/FCM 或自動扣繳。
