# 農場依天氣加權隨機收成

## 原因與確認規格

使用者希望每次每塊田收成改為 1～5 個，正常時中間值較多、壞天氣未防護時兩端較多，並已確認以下機率：

| 個數 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 正常／已防護 | 5% | 40% | 30% | 20% | 5% |
| 全程惡劣且未防護 | 30% | 25% | 20% | 15% | 10% |

依本期成長期間未防護的不良條件時間占比，線性插值兩組權重；壞天氣提高兩端機率，但平均從 2.8 降至 2.5。

## 實作與取捨

- `lib/farm/farm_growth.dart` / Cloud `src/services/game/growth.py`：累積成熟前經歷的總時間與不良時間，成熟時即固定產量。保留原本玩家、田地、原始播種時間與採收次數的 seed，重讀、失敗重試或成熟後等天氣不會重抽。多次採收的作物每一期重設統計。
- 不良條件包含未防護的強風、豪雨、非冬季作物遇寒流、晴熱失水，以及蟲害，沿用現有天氣門檻。溫室擋天氣；防風網只擋風；晴天娃娃擋自然豪雨；雨雲罐／灑水器避免晴熱失水。肥料及補光燈不等於通用天氣保護。正常雨、陰天、夜晚與缺天氣的中性降級不算壞天氣。
- 蟲害由除蟲／殺蟲劑處理，改以存在期間計入不良時間。原本風害、蟲害在收成後相乘的減產改由上述機率取代，避免重複處罰並保留完整 1～5 分布。舊 `*YieldMultiplier` 設定欄位保留作為歷史相容資料，目前不再套用。
- `FarmPlot` / `FarmSaveCodec` 新增 `yieldGrowingMicros`、`yieldAdverseMicros`、`readyYield`，放在既有 plot JSON 中，不更改 DB schema；缺欄位視為零，既有成熟作物按正常分布固定。不回溯推測升級前天氣。備份、Cloud 搬遷與作弊器快轉保留欄位。Cloud 匯入驗證數值範圍，並接受舊存檔。
- 兩端的 `balance_v1.json` 統一所有作物範圍 1～5、加入兩組權重；保留 `version=1`，因為同一尚未發布的 4.0 開發版仍用它作為存檔／搬遷契約及行情 seed。部署時仍必須 Cloud 先於 App；舊 App 的純單機算法不會自行更新。
- Cloud `engine.py`：新舊規則切換時，已被偷的舊成熟作物可能有超過新產量的 `stolen_qty`；扣除後至少留一個給主人，防止負的收成價值進排行榜。新收成照既有偷菜保留比例運作。

入口：農場 → 播種／照顧田地 → 成熟後點收成，沿用既有流程。依使用者要求，不新增隨機收成引導，`farm.guide.home.v4` 維持原有田地與天氣說明；保留 4.0.0 新功能公告。Web 目前只有公開農場排行榜、沒有種植／收成操作，因此同步修改 Cloud 遊戲規則，無對應 Web 控制項。部署順序仍為 Cloud → Web（本次無變更）→ App。

## 經濟影響

人工檢查 `FarmSimulation` 的 12 週輸出後，同步更新兩端 `economy_v1.json` 與 SHA manifest：固定六田的普通玩家平均週淨利從 2189.25 降至約 1452.33，好好照顧的玩家從約 2587.33 降至 1559；普通玩家擴至十二田由模擬第 7 週變成第 12 週。懶散玩家維持約 403.5、無收成。這是統一低產量的預期結果，本次不連帶調種子／作物售價、XP、獎勵或擴田價格；同步更新對應的經濟回歸預期。

## 驗證

- 新增 Dart / Python 的分布、各種天氣及對應道具、到期中斷、分段推進、成熟後固定、多期採收、舊存檔及無效匯入測試。
- 新增 `yield_v1.json`：80 組 seed，各含正常／半數惡劣／全程惡劣三種產量，以獨立 FNV-1a／SplitMix64 參考與手算累計區間建立，兩端實際執行驗證同樣 240 個結果；包含全部 1～5 個輸出。
- Cloud 容量、板條箱、偷菜及市場測試原本指定 6 個的測資改成 5 個，相關數量斷言跟著更新。
- 全農場 Flutter 測試：292 通過、2 個既有文案測試失敗（排行榜仍期待公開公式、週結算仍期待精確算式；工作樹先前已去除公式，見 `2026-10-16-farm-help-text-vague.md`）。本次未恢復已移除的公式或調整這兩個無關測試。

最終檢查：本次相關 Flutter 測試 74 項全數通過；Cloud 全遊戲測試通過，後續新增的舊存檔匯入／無效狀態／舊偷菜扣量測試亦隨 API 全檔通過。修改檔案 Dart analyze、Python Ruff、跨端 SHA 檢查及兩 repo diff 空白檢查通過。尚未部署。
